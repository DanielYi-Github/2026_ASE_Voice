## 🎨 二、 視覺設計規範 (Visual Identity & Color System)

本屆官方網站採用 **Neo-Brutalism（新野獸主義）與高質感現代暗色舞台（Apple 發表會暗黑美學）** 相結合的設計語言。配合主管希望「**偏黑紅色**」、「**單純簡約**」、「**質感大器**」的原則，背板與各類視覺輸出建議遵循以下色系與元素配比：

### 1. 標準色系與配比建議（黃金 70 : 20 : 10 原則）

```
■ 深邃碳黑 (70%)        ■ 烈焰熱血紅 (20%)       ■ 榮耀冠軍金 (10%)       □ 純白/象牙米
HEX: #0C0C0C / #1A1A1A   HEX: #E32626             HEX: #F5B841 / #FFC107   HEX: #FFFFFF / #F6E9D8
CMYK: 75, 68, 67, 90     CMYK: 0, 95, 90, 0       CMYK: 0, 28, 85, 0       CMYK: 0, 0, 0, 0
用途：背景底色、沉浸感   用途：LIVE標章、張力亮點 用途：主標、冠軍榮譽、光芒 用途：遠距文字、高對比閱讀
```

* **70% 深邃碳黑底色 (`#0C0C0C` ~ `#1A1A1A`)**：沉穩大器、避免反光，凸顯台上選手與燈光層次。
* **20% 烈焰激情紅 (`#E32626`)**：營造決賽現場直播、對決張力與熱血氣氛。
* **10% 榮耀冠軍金 (`#F5B841` / 金屬光澤金)**：象徵最高榮譽、獎盃與聚光燈。
* **純白 (`#FFFFFF`)**：主要資訊文字、高對比度確保遠距離清楚易讀。

### 2. 建議字體 (Typography)
* **中文標題**：`Noto Sans TC` (Black 900 / Bold 700)、俐落粗黑體、蒙納超剛黑。
* **英文標題**：`Oswald` (Bold)、`Bebas Neue`、`Inter`（大寫字母，字距 Tracking 建議設為 `+0.2em` ~ `+0.4em`）。
* **內文與時程**：`Inter`、`Noto Sans TC` (Regular / Medium 500)。

### 3. 核心視覺圖素 (Key Visual Elements)
* **主體元素**：復古金屬電台麥克風（Vintage Shure 55SH 風格，自帶金屬反光與微光聚光燈）。
* **背景氛圍**：金屬音波跳動線（Waveform Bars）、放射光芒（Sunburst）、微網點（Halftone Dots）。
* **設計禁忌**：避免過多花俏卡通插圖、避免雜亂無章的漸層；保持「黑底、金色光澤、大字距」以維持最高質感。

```text
+-----------------------------------------------------------------------------------------+
| [基金會 / 福委會 Logo]                                                    [LIVE 直播標記] |

|                             ASE VOICE 2026 · GRAND FINALE                               |

|                                                                                         |
|~~~~~~~~~~~~~~~~~~~~ ⚠️ 舞台視線遮擋安全線（離地 100~120cm 以下）~~~~~~~~~~~~~~~~~~~~~~~~~~|
|                                                                                         |
| 主辦單位：...          協辦單位：...          承辦單位：日月光流行音樂歌唱社                  |
+-----------------------------------------------------------------------------------------+
```

1. **核心資訊置頂（上半部 60% 安全區）**：
   * 舞台上有講台、立式麥克風架、主持人及得獎選手站立，**請務必將「活動主標題」、「日期」及「LOGO」排在背板上方 2/3 範圍內**，避免拍照時被擋住。
2. **輸出解析度與色彩格式**：
   * **印刷實體背板**：色彩模式設定為 **CMYK**，解析度依實際比例（1:1 時至少 100~150 DPI；1:10 縮圖時需 300 DPI 向量向量稿）。
   * **LED 電子大螢幕**：色彩模式設定為 **RGB**，解析度建議輸出 `1920x1080 (16:9)` 或現場實際螢幕 Pixel 點對點解析度。
